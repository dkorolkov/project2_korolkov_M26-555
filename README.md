## Управление таблицами

### create_table создать таблицу

`create_table <имя_таблицы> <столбец1:тип> <столбец2:тип>`

Создаёт таблицу с заданным именем и столцами с указанными именами и типами.
Имя таблицы и имена столбцов должны быть допустимыми идентификаторами:
начинаться с английской буквы и содержать только английские буквы и цифры.
Допустимые типы столбца: int, bool, str.
Сообщает об ошибке, если таблица уже существует,имена столбцов повторяются
или указан недопустимый тип столбца.
При успешном выполнении выводит сообщение:
`Таблица <имя> успешно создана`

#### Примеры

`create_table tab1 col1 : int col2:str col3: bool`

`create_table tab1 id:int name:str active:bool`

### drop_table удалить таблицу

`drop_table <имя_таблицы>`

Удаляет таблицу с заданным именем.
Сообщает об ошибке, если указанной таблицы не существует.
При успешном выполнении выводит сообщение:
`Таблица <имя> успешно удалена`

#### Примеры

`drop_table tab1`

### list_tables вывести список всех таблиц

`list_tables`

Выводит имена всех сушествующих в базе данных таблиц по одной
на каждой строке. Если таблиц нет, выводится сообщение:
`База данных не содержит ни одной таблицы`

#### Примеры

`list_tables`

## Управление данными

### insert

`insert into <имя_таблицы> values (<значение1>, <значение2>, ...)`
Вставить строку в таблицу.

#### Примеры

`insert into tab1 values (5 "qwerty" true)`

### select

`select from <имя_таблицы>`
Вывести все строки таблицы.

`select from <имя_таблицы> where <столбец> = <значение>`
Вывести строки таблицы, удовлетворяющие условию.

#### Примеры

`select from tab1`

`select from tab1 where col1 = 5`

`select from tab1 where col2 = "qwerty"`

`select from tab1 where col3 = false`

### update

` update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>`
Установить новое значение указанного столбца во всех строках, удовлетворяющих условию.

#### Примеры

`update tab1 set col1=6 where col1 = 5`

`update tab1 set col3 = true where col2 = "qwerty"`

`update tab1 set col2="" where col3 = false`

### delete

`delete from <имя_таблицы> where <столбец> = <значение>`
Удалить все строки, удовлетворяющие условию.

#### Примеры

`delete from tab1 where col1 = 5`

`delete from tab1 where col2 = "qwerty"`

`delete from tab1 where col3 = false`

### info

`info <имя_таблицы>`
Вывести информацию о таблице.

#### Примеры

`info tab1`
